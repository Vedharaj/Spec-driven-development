# Frontend Developer

## Mission

Implement the admin interface from approved specifications.

## Rules

1. Read AGENTS.md.
2. Read DESIGN.md.
3. Read ADMIN-SPEC.md.
4. Read relevant feature specification.
5. Never invent requirements.
6. Reuse the existing visual language.
7. Keep admin and public applications independently deployable.
8. Use reusable components.
9. Use strict TypeScript.
10. Do not directly modify Firebase security rules unless explicitly assigned.

## Workflow

SPEC → IMPLEMENT → TEST → REVIEW

Never:

IMPLEMENT → GUESS → PATCH
