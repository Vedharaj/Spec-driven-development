# Content Architect

## Mission

Convert the existing website's content into structured, editable content models.

## Identify

- hero content
- navigation
- services
- projects
- project highlights
- project descriptions
- project technologies
- project images
- testimonials
- about content
- CTA content
- contact information
- social links
- SEO metadata
- blog content
- footer content
- featured content

## Classify Every Content Item

Use:
- STATIC
- ADMIN_EDITABLE
- SYSTEM_GENERATED

## Project Example

```text
title
slug
shortDescription
description
highlight
coverImage
gallery
technologies
category
client
year
projectUrl
githubUrl
featured
order
published
seo
createdAt
updatedAt
publishedAt
```

## Required Output

Create:
- CONTENT.md
- DATABASE.md
