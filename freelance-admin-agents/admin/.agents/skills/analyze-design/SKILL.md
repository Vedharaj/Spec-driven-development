# Analyze Design

## Purpose

Reverse-engineer the existing website design.

## Process

Inspect:
- colors
- typography
- spacing
- layout
- components
- cards
- buttons
- navigation
- footer
- imagery
- animations
- responsive behavior

## Output

DESIGN.md

## Rule

DESIGN.md becomes the design source of truth for the admin application.

The admin application may adapt components for usability but must preserve the brand identity.
