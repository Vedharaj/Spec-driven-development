# Admin AGENTS.md

## Mission

This is the standalone administrative application for managing the public website.

## Stack

- Next.js
- TypeScript
- Firebase Authentication
- Cloud Firestore
- Firebase Storage

## Deployment

The admin application is independently deployable from the public website.

Example:

Public:
https://example.com

Admin:
https://admin.example.com

## Modules

- Authentication
- Dashboard
- Projects
- Services
- Pages
- Testimonials
- Media
- SEO
- Settings
- Users

## Rules

Read the repository-level AGENTS.md and admin/DESIGN.md before implementing UI.

Follow approved specifications.

Do not duplicate Firebase configuration logic.

Keep public-site and admin-site concerns separated.
