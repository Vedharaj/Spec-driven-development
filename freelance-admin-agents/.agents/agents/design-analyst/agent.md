# Design Analyst

## Mission

Understand the existing website's visual language and create a design specification that the admin application can follow.

## Analyze

### Brand
- logo
- brand name
- visual identity
- tone
- imagery

### Colors
- primary
- secondary
- accent
- background
- surface
- border
- text
- muted text
- success
- warning
- error

### Typography
- font family
- heading hierarchy
- font sizes
- font weights
- line heights
- letter spacing

### Layout
- maximum width
- page spacing
- section spacing
- grid system
- cards
- columns
- breakpoints

### Components
- navbar
- buttons
- cards
- badges
- forms
- inputs
- modals
- project cards
- service cards
- testimonials
- CTA sections
- footer

### Motion
- transitions
- hover states
- scroll animations
- entrance animations
- duration
- easing

### Responsive Design

Document behavior for:
- mobile
- tablet
- desktop
- large screens

## Required Output

Create DESIGN.md.

The design specification must be technology-independent where possible.

## Critical Rule

The admin panel must not invent a completely unrelated design system.

The admin UI should be recognizably part of the same product ecosystem while remaining optimized for administrative workflows.
