# Content Management

Content should be separated from application code whenever it is expected to change through the admin panel.

Before making a field editable, determine:
1. Where it currently lives.
2. Whether it is public.
3. Whether it changes frequently.
4. Whether a non-developer needs to edit it.
5. Whether it affects SEO.
6. Whether it contains media.
7. Whether it needs publishing.
8. Whether it needs ordering.

Do not turn application logic into editable content.
