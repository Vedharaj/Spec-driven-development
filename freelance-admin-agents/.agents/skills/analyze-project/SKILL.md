# Analyze Existing Project

## Purpose

Understand the existing application before development.

## Process

1. Inspect repository structure.
2. Inspect package.json.
3. Identify Next.js architecture.
4. Map routes.
5. Map components.
6. Identify content.
7. Identify assets.
8. Identify data sources.
9. Identify design patterns.
10. Identify hardcoded content.
11. Identify reusable components.
12. Document findings.

## Output

- PROJECT-MAP.md
- ARCHITECTURE.md
- CONTENT.md

## Constraint

Do not modify application code.
