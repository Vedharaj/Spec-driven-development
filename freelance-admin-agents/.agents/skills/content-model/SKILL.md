# Content Model

Before creating an admin field, determine:

1. Where is the content currently defined?
2. Is it visible publicly?
3. Does it change frequently?
4. Does a non-developer need to edit it?
5. Does it affect SEO?
6. Does it contain media?
7. Does it require publishing?
8. Does it require ordering?

Only then convert it into an admin-managed field.

Do not turn application logic into editable content.
