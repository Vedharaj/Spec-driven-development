# SKILL.md

## File Name
`SKILL.md`

## Description
Skill for maintaining clear, professional, and traceable communication with freelance clients.

## Process
Discuss → Clarify → Document → Confirm → Execute → Demo → Feedback → Record Decision

## Rules
- Keep important decisions written.
- Confirm scope changes.
- Communicate blockers early.
- Use simple language with clients.
- Show working progress regularly.
- Never promise an unclear deadline.
